# Vacpack

Vacpack makes images, videos and GIFs smaller, entirely offline. It has a native macOS app and CLI, and an experimental native Windows app. Like vacuum packing: everything the file does not need is pumped out.

**Windows preview:** a self-contained x64 installer and portable ZIP, with photo/video thumbnails, a cancellable queue and local image, video, GIF and audio processing. .NET is included; FFmpeg and ffprobe are installed separately. The interface is English by default, with Russian as a choice. See [Windows/README.md](Windows/README.md) for installation and limitations, or the [0.5.1 release](https://github.com/kureinmaxim/vacpack/releases/tag/v0.5.1).

**Version:** `0.6.3`, released 23.10.2026 · [changelog](CHANGELOG.md) · [how versions are managed](VERSION_MANAGEMENT.md)

## What works today on macOS

- **Images** — JPEG, PNG, WebP, AVIF, HEIC/HEIF, TIFF, BMP and SVG in (DNG is supported but not yet tested); JPEG, PNG, WebP, AVIF or the same format out. Five quality levels, six resize modes (never upscaling), EXIF orientation applied, transparency kept (or flattened to white for JPEG). EXIF/IPTC/XMP, color profile, print resolution, file dates and Finder tags can be kept.
- **Videos** — MP4, MOV, WebM, MKV and other containers in; MP4, MOV, WebM or the same container out, or just the sound as M4A, MP3 or Opus: a speech profile (mono, even loudness, about 29 MB an hour) makes podcasts and voice files for Telegram, Delta Chat and other messengers, with a frame from the video as cover art; share a finished file from the window. H.264 or HEVC with x264/x265 (VideoToolbox optional on Apple Silicon), VP9 + Opus for WebM, output bitrate capped below the source's so already-compressed videos still shrink, transparency kept in WebM and MOV, every audio track kept, resolution presets and frame-rate caps that only ever go down. Falls back to software encoding when the media engine is busy.
- **GIFs** — compress animated GIFs or turn videos into GIFs with gifski: quality, size and frame rate (10–50 fps), transparency and frame timing preserved.
- **Safe by default** — a result that is not smaller never replaces the original, originals go to the Trash only after success, and nothing ever leaves your Mac.

## Windows

Download the installer or ZIP from the [0.6.3 release](https://github.com/kureinmaxim/vacpack/releases/tag/v0.6.3). Both include the .NET runtime. Install [FFmpeg for Windows](https://ffmpeg.org/download.html#build-windows) separately (the **full** build from gyan.dev has every encoder below); the app lets you choose its `bin` directory. Windows currently supports a subset of the macOS features; see [the Windows guide](Windows/README.md).

- **Strong compression** — for when a 1 GB video has to become 10 MB: pick a modern codec (AV1, HEVC or H.266), tell it the size to fit into, and trade resolution, frame rate, colour and sound quality for it. Details: [docs/STRONG_COMPRESSION.md](docs/STRONG_COMPRESSION.md).
- **When something fails**, “Details” says what happened, up to three things to try, and FFmpeg's exit code; the full command and output are kept in `%LOCALAPPDATA%\Vacpack\logs\last-error.txt`.

## Requirements for macOS

- macOS 14 or later, Xcode 26 (after installing or updating Xcode, run `sudo xcodebuild -runFirstLaunch` once)
- Tools from Homebrew:

```bash
brew install xcodegen ffmpeg pngquant gifski webp libavif ghostscript
```

Vacpack runs these tools as separate programs and never links them, so their licenses apply to them alone.

## Build and test

```bash
scripts/bootstrap.sh   # check prerequisites, generate the Xcode project and test inputs
scripts/check.sh       # swift-format lint, engine tests, app build and tests (--ui adds UI tests)
open Vacpack.xcodeproj
```

`Vacpack.xcodeproj` is generated from `project.yml` with XcodeGen and is not committed.

The step-by-step build guide, from a fresh clone to the DMG, with common problems: [BUILD.md](BUILD.md) (in Russian).

The app icon is drawn in code (`design/AppIcon.swift`); `scripts/make-icon.sh` renders every macOS size into the asset catalog.

## Install on your Mac

```bash
scripts/package.sh   # build Release and pack .build/dist/Vacpack-<version>.dmg
scripts/install.sh   # install that DMG into Applications and refresh the Dock icon
```

The app is a universal build (Apple Silicon and Intel). `install.sh` restarts the Dock, which otherwise can keep a blank cached icon after a reinstall. To install by hand instead, `scripts/package.sh --open` opens the DMG in Finder; drag **Vacpack** into **Applications**.

The build is ad-hoc signed, not notarized: it opens without warnings on the Mac that built it, while on other Macs macOS blocks it until you choose **System Settings → Privacy & Security → Open Anyway**. Those Macs also need the Homebrew tools listed above.

## Command line

The engines are a Swift package (`Packages/CompressorKit`) with a `vacpack` command:

```bash
swift run --package-path Packages/CompressorKit vacpack tools
swift run --package-path Packages/CompressorKit vacpack image photos/ --format webp --max-long-edge 2000
swift run --package-path Packages/CompressorKit vacpack video clip.mov --format mp4 --resolution 1080p
swift run --package-path Packages/CompressorKit vacpack video clip.mov --format gif --gif-fps 15 --gif-max-width 480
swift run --package-path Packages/CompressorKit vacpack gif animation.gif --quality good --percent 50
```

`image`, `video` and `gif` describe their options with `--help`; every command can print results as `--json`.
