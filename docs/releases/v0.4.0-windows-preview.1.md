# Vacpack 0.4.0 — Windows preview 1

Первый предварительный Windows-релиз.
Тег: `v0.4.0-windows-preview.1`, дата: 19.10.2026. Это Windows-релиз; новый DMG
для macOS в него не входит. Последний стабильный macOS-релиз — `v0.3.1`.

## Что добавлено

- Нативное окно Windows с перетаскиванием файлов и папок, очередью, прогрессом и отменой.
- Миниатюры фото, видео и GIF загружаются в фоне; поддержаны EXIF-поворот фото и короткие видео.
- Сжатие JPEG, PNG, WebP, AVIF, TIFF, BMP, видео H.264/VP9 и GIF; извлечение M4A, MP3, Opus, включая профиль речи.
- Настройки под типы файлов, действия в строках и повторное сжатие с новыми настройками.
- Исходники сохраняются. Результат записывается только при уменьшении, без перезаписи существующих файлов.

## Установка

- `Vacpack-Setup-0.4.0.exe` — установщик для Windows x64, установка в профиль пользователя и деинсталлятор.
- `Vacpack-0.4.0-windows-preview.1-win-x64.zip` — переносимая папка `Vacpack`; распакуйте целиком и запустите `Vacpack.exe`.
- `SHA256SUMS.txt` — SHA-256 обоих файлов. Проверка в PowerShell: `Get-FileHash .\Vacpack-Setup-0.4.0.exe -Algorithm SHA256`.

В обоих вариантах .NET 8.0.32 входит в поставку. FFmpeg и ffprobe устанавливаются
отдельно: [Windows-сборки FFmpeg](https://ffmpeg.org/download.html#build-windows).
Папку с `ffmpeg.exe` и `ffprobe.exe` можно выбрать в окне приложения; также
поддерживаются `VACPACK_TOOLS`, `tools` рядом с EXE, `PATH` и установленный Scoop.
Установщик и приложение пока не подписаны цифровым сертификатом.

## Проверено

27 проверок движка, 8 проверок миниатюр и запуск WPF-окна с заполненной очередью.
Проверяются сохранность исходников, коллизии имён, прозрачность, звук и длительность,
отмена дерева процессов, EXIF-поворот, короткое видео и отсутствие блокировки фото.
Оба пакета собираются из одной staging-папки после фиксации исходников.
Внутри папки приложения `BUILD.json` содержит исходный коммит и `sourceDirty: false`.

## Ограничения

Пока нет HEIC/HEIF, DNG, SVG, APNG, HDR, PDF/EPUB, аппаратного кодирования, HEVC
на выходе, переноса EXIF/IPTC/XMP/ICC, тёмной темы и сохранения настроек. PNG
сжимается без потерь; GIF использует FFmpeg вместо gifski. Windows 10 и ARM64
отдельно не проверены. Приложение обрабатывает файлы локально.
